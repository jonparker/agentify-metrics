# AGENTS.md — Claude Code Automation

This document outlines how Claude Code agents can assist with agentify-metrics development and maintenance.

## Available Agents

### General Purpose Agent
- **Use for**: Open-ended exploration, multi-step research, cross-file analysis
- **Examples**: 
  - Investigating why coverage dropped in a particular directory
  - Refactoring chart initialization code
  - Adding new visualization types

### Plan Agent (Recommended for Features)
- **Use for**: Designing implementation approaches before coding
- **Examples**:
  - Adding support for branch coverage comparison
  - Integrating a new data source or metric type
  - Redesigning dashboard layout

### Explore Agent
- **Use for**: Codebase navigation and discovery
- **Examples**:
  - Finding all Chart.js configuration points
  - Locating data validation logic
  - Tracing how metrics flow from data files to UI

### Code Review Agent
- **Use for**: Security and quality reviews
- **Examples**:
  - Reviewing deployment workflow security
  - Auditing data handling in frontend code
  - Checking for XSS vulnerabilities in data rendering

## Common Workflows

### Updating Data Pipeline

When metrics source format changes:
1. Use **Plan agent** to design schema updates
2. Update `data/latest.json` and `data/history.json` structure
3. Use **Code review agent** to verify data validation

### Adding Dashboard Features

Adding a new chart or metric type:
1. Use **Plan agent** to review Chart.js capabilities and design UI
2. Implement visualization in `index.html`
3. Use **Code review agent** to check DOM safety and rendering

### Deployment Troubleshooting

If Pages deployment fails:
1. Use **General purpose agent** to debug workflow logs
2. Verify Cloudflare account configuration
3. Check GitHub secrets are properly configured

### For Exploration
> "Find all places where we parse or validate coverage JSON data."

> "What Chart.js plugins are currently in use and where?"

### For Implementation
> "Add a toggle to show/hide uncovered files in the directory breakdown chart."

> "Update the deployment workflow to also update a changelog entry."

## Tools Used

- **Read/Write**: JSON data files, HTML/JS source, workflow files
- **Bash**: Running local dev server, git operations, npm scripts
- **Notion** (optional): Linking dashboard to project tracking
- **GitHub**: Reviewing deployment logs, managing secrets

## Data Safety

- **Data files** (`data/*.json`) are committed to git; treat as source of truth
- **Generated files** from agentify test runs are committed after each build
- **Secrets** (`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`) stored as GitHub secrets only
